# Format naskah — STORYBOOK (buku cerita bergambar)

Ceritamu jadi buku cerita anak sungguhan di atas meja, di bawah lampu baca: sampul tertutup, sampul dibuka, lalu
halaman demi halaman dibalik. Gambarnya kertas yang digunting dan dicat (cat air, krayon, guas), tokohnya boneka kertas
dengan paku keling kuningan yang bisa jalan, melambai, menangis, melompat, tidur, dan terbang. Tulisan cerita tercetak
di halaman, di bawah gambarnya, dan dibacakan narator.

Kirim `naskah.txt` dengan format di bawah, plus VO (`vo.mp3`) kalau sudah ada.

## Aturan
1. **Kepala naskah** (sekali, di atas):
   - `JUDUL:` — dicetak di sampul dan halaman judul.
   - `OLEH:` — nama penulis (opsional).
   - `PERSEMBAHAN:` — kalimat untuk halaman judul (opsional).
   - `TOKOH: Nama = deskripsi` — satu baris per tokoh, dideklarasikan sekali saja.
2. **`[SAMPUL]`** (opsional): suasana sampul dan siapa yang tampil. Kalimat di bawahnya dibacakan saat sampul masih
   tertutup, misalnya judulnya.
3. **`[HALAMAN]`** = satu halaman buku. Di baris tag tulis tempat, waktu, benda, dan apa yang dilakukan tiap tokoh.
   Baris-baris di bawahnya adalah teks halaman: dicetak di bawah gambar dan dibaca narator.
4. **Panjang teks per halaman:** 1–3 kalimat pendek (sampai ±25 kata). Idealnya 4–10 halaman.
5. **`[PENUTUP] Tamat`** (opsional): dicetak miring di bawah teks halaman terakhir. Di akhir video lampu meredup.

## Tokoh
`TOKOH: Raka = anak laki-laki, rambut pendek hitam, kaos kuning, celana pendek biru`

- **Orang:**
  - umur: anak · ibu / ayah / guru (dewasa) · nenek / kakek;
  - rambut: bob, kuncir dua, pendek, panjang, sanggul, botak, hijab / kerudung, peci;
  - pakaian: gaun, rok panjang / kebaya, jubah / gamis, kaos + celana pendek, baju + celana panjang;
  - warna untuk baju / celana / rambut / hijab: merah, merah muda, oranye, kuning, hijau, toska, biru, biru muda,
    biru tua, ungu, coklat, krem, putih, hitam, abu;
  - motif: berbintik (polkadot), bergaris;
  - tambahan: kacamata, berjenggot.
- **Hewan & teman ajaib:** kucing, kelinci, anjing, burung, bebek, ikan, kupu-kupu, bintang (bintang hidup yang punya
  wajah). Warna bisa ditambahkan, misalnya `kucing oranye`.

## Baris halaman
`[HALAMAN] mendung, kebun, hujan, payung. Raka memegang payung, Mimi menangis.`

- **Waktu:** pagi, siang, senja / sore, malam, mendung (hujan).
- **Tempat:** kebun / halaman, taman, desa, hutan, pantai, laut, gunung, sawah, sungai, kamar, sekolah, kota, langit.
- **Benda:** rumah, pohon, bunga, semak, awan, bulan, matahari, bintang, pelangi, hujan, perahu, layang-layang, balon,
  lentera / lampion, kado, buku, payung, tempat tidur, lampu, kupu-kupu, burung, kelapa, cemara, kilau.
- **Aksi tokoh** (tulis nama tokoh, lalu kata kerjanya):
  - berdiri, berjalan, berlari, melompat, melambai, menunjuk, menatap / mendongak;
  - senang / tertawa, sedih, menangis, terkejut;
  - duduk, tidur;
  - memeluk (sebut siapa yang dipeluk);
  - mengintip dari jendela;
  - jatuh (dari langit), terbang, berenang;
  - membawa layang-layang, memegang balon / lentera / payung.

## Contoh
```
JUDUL: Mimi dan Payung Kuning
OLEH: Voynann
PERSEMBAHAN: untuk yang suka berbagi payung
TOKOH: Raka = anak laki-laki, rambut pendek hitam, kaos kuning, celana pendek biru
TOKOH: Mimi = kucing oranye
TOKOH: Ibu = ibu berhijab hijau, baju krem

[SAMPUL] siang, kebun. Raka melambai, Mimi.

[HALAMAN] pagi, kebun, rumah, pohon, bunga. Raka berjalan.
Pagi itu, Raka berjalan-jalan di kebun.

[HALAMAN] mendung, kebun, hujan, semak. Mimi menangis.
Tiba-tiba hujan turun. Di balik semak, ada kucing kecil yang kedinginan.

[HALAMAN] mendung, kebun, hujan, payung. Raka memegang payung, Mimi.
Raka membagi payung kuningnya dengan si kucing kecil.

[HALAMAN] malam, kamar, tempat tidur. Raka tidur, Mimi tidur.
Malamnya, Raka dan Mimi tidur bersama. Sahabat baru, hati yang hangat.

[PENUTUP] Tamat
```

## VO
- Teks VO = semua kalimat halaman berurutan, ditambah kalimat di bawah `[SAMPUL]` kalau ada. Tag tidak dibaca.
- VO-mu tidak dipercepat atau dipotong. Halaman-halamannya saja yang diberi jeda, supaya tiap balik halaman jatuh di
  antara kalimat.
- Tanpa VO, narasi sementara bisa dibuat dengan suara macOS. Untuk versi jual, rekam VO-mu sendiri, misalnya di
  ElevenLabs dengan suara lembut pendongeng.

==== 1186 project/README.md
# VOYNANN Motion — STORYBOOK project

A picture-book script (`stories/<id>/naskah.txt`, see `FORMAT-NASKAH-BUKU.md`) plus its narration becomes a real paper
storybook on a table: the cover, the opening, a page turn per page, painted cut-paper pictures with paper puppets, the
text printed under each picture, a music-box lullaby, and the reading lamp dimming at the end. 9:16, 1080×1920 @ 60;
add `--wide` for 16:9 (1920×1080 @ 60: the open book as a two-page spread, text on the left page, picture on the right).

```
npm ci
npm run check-env
npm run smoke                                   # four stills of the example → out/smoke/_sheet.jpg
node scripts/book-make.mjs mimi --plan          # read the plan + warnings
node scripts/book-make.mjs mimi --tts --preview # temporary macOS voice, 540×960
node scripts/book-make.mjs mimi --final         # with stories/mimi/vo.mp3 → out/mimi/mimi_1080x1920_60fps.mp4 + QA
node scripts/book-make.mjs mimi --final --wide  # 16:9 → out/mimi/mimi_1920x1080_60fps.mp4 + QA in out/mimi/qa-wide
```

All sound is synthesised in `scripts/book-sound.mjs` (no samples). Fonts: Newsreader and Kalam (SIL OFL 1.1, licences in
`public/fonts`).

==== 1469 project/scripts/gl.mjs
// WebGL renderer choice for headless Chrome, shared by every render script.
// Order: GL env var > the project's .gl-mode file > "angle" (GPU). When the GPU path cannot create a WebGL
// context (no GPU, some VMs/drivers), the scripts switch to "swangle" (software, much slower) automatically
// and remember it in .gl-mode, so later renders and `npx remotion render` (remotion.config.ts) use it too.
import fs from "node:fs";

const FILE = ".gl-mode";

// When the GPU path crashes, Remotion may reject an internal "Target closed" promise that nothing awaits.
// That rejection is noise from the dead tab, not a render failure; real errors still reach the caller.
export const tolerateClosedTargets = () =>
  process.on("unhandledRejection", (e) => {
    if (/Target closed/i.test(String(e?.message ?? e))) return;
    console.error(e);
    process.exit(1);
  });

export const glMode = () =>
  process.env.GL || (fs.existsSync(FILE) ? fs.readFileSync(FILE, "utf8").trim() : "") || "angle";

export const isWebGLError = (e) =>
  /webgl|WebGLRenderer|GL context|BindToCurrentSequence|GL_VENDOR = Disabled/i.test(String(e?.stack ?? e?.message ?? e));

export const switchToSoftware = () => {
  fs.writeFileSync(FILE, "swangle\n");
  console.log(
    "\n! GPU 3D rendering is not available on this computer: switched to software rendering (GL=swangle, much slower)." +
      "\n  Saved in .gl-mode; delete that file to try the GPU again.\n",
  );
  return "swangle";
};

==== 3676 project/scripts/stills.mjs
// Visual QA: bundle once, render chosen frames of a composition, tile them into a contact sheet.
//   node scripts/stills.mjs <outDir> <frame,frame,...> <compositionId> [scale]
// Frames may be given in seconds with an "s" suffix (e.g. 4.5s), using the composition's fps.

import path from "node:path";
import fs from "node:fs";
import { execFileSync } from "node:child_process";
import { bundle } from "@remotion/bundler";
import { openBrowser, renderStill, selectComposition } from "@remotion/renderer";
import { glMode, isWebGLError, switchToSoftware, tolerateClosedTargets } from "./gl.mjs";

tolerateClosedTargets();

const [outDir, list, id, scaleArg = "1", propsFile] = process.argv.slice(2);
const inputProps = propsFile ? JSON.parse(fs.readFileSync(propsFile, "utf8")) : {};
if (!outDir || !list || !id) {
  console.error("usage: node scripts/stills.mjs <outDir> <frame,frame,...|4.5s,...> <compositionId> [scale]");
  process.exit(1);
}
fs.mkdirSync(outDir, { recursive: true });

const serveUrl = await bundle({ entryPoint: path.resolve("src/index.ts") });
// bundles are ~50 MB each; never leave them in the temp dir, even when a render throws
const cleanup = () => fs.rmSync(serveUrl, { recursive: true, force: true });
process.on("exit", cleanup);
const composition = await selectComposition({ serveUrl, id, inputProps });
const frames = list.split(",").map((t) => (t.endsWith("s") ? Math.round(parseFloat(t) * composition.fps) : parseInt(t, 10)));
const files = [];
const renderAll = async (gl) => {
  // one browser for all stills: WebGL contexts are expensive to create and tear down
  const puppeteerInstance = await openBrowser("chrome", { chromiumOptions: { gl } });
  try {
    files.length = 0;
    for (const frame of frames) {
      const output = path.join(outDir, `f${String(frame).padStart(4, "0")}.png`);
      await renderStill({ composition, serveUrl, output, frame, inputProps, scale: Number(scaleArg), chromiumOptions: { gl }, timeoutInMilliseconds: 180000, puppeteerInstance });
      files.push(output);
      process.stdout.write(`${frame} `);
    }
  } finally {
    // after a WebGL crash the tab may already be gone; closing must not hide the original error
    await puppeteerInstance.close({ silent: true }).catch(() => {});
  }
};
const gl = glMode();
try {
  await renderAll(gl);
} catch (e) {
  if (gl === "swangle" || !isWebGLError(e)) throw e;
  await renderAll(switchToSoftware());
}
console.log();
cleanup();

// contact sheet (needs ffmpeg; skipped if missing)
try {

==== 8208 project/src/core/geometry/slab.ts
// Parametric rounded slab with a FIXED topology: every parameter change only moves
// vertices, so a slab can morph continuously from a 1990s brick to a 2026 glass slab
// (or a sensor orb) with no remeshing, popping or flicker.
//
// Surface = outline (front view, rounded rectangle with per-corner radius) × side profile
// (front cap → front fillet → side wall with optional seam groove → back fillet → back cap).
// The outline is offset inward by the profile inset; corners use the exact inward offset of
// a rounded corner (radius rc − inset, mitred once the inset exceeds rc), so the same
// generator makes sharp-cornered modules, rounded phones and — with rc = hw = hh and
// fillets = d/2 — a sphere. Normals are analytic (sharp edges stay sharp).

import { BufferAttribute, BufferGeometry, Sphere, Vector3 } from "three";

export type SlabSpec = {
  /** Half width (x), half height (y), full depth (z). */
  hw: number;
  hh: number;
  d: number;
  /** Outline corner radius, or per corner [TR, TL, BL, BR]. */
  rc: number | readonly [number, number, number, number];
  /** Front / back edge fillet radii. */
  reF: number;
  reB: number;
  /** Groove around the side wall (z of its centre, depth, width). */
  seamZ?: number;
  seamDepth?: number;
  seamWidth?: number;
  /** Dome height of the front / back caps. */
  bulgeF?: number;
  bulgeB?: number;
  /** Offset added to the shader-space position attribute `tfPos` (e.g. a module's place in its parent). */
  origin?: readonly [number, number];
  /** Planar UV: u = (x + origin.x) / uvSize.x + 0.5. */
  uvSize?: readonly [number, number];
};

const N_CORNER = 10; // segments per corner arc
const CAP_RHO = [0, 0.38, 0.68, 0.88]; // cap rings (edge ring comes from the fillet)
const N_FILLET = 8;
const GROOVE_U = [0.85, 0.5, 0.18, 0, -0.18, -0.5, -0.85];

const P = 4 * (N_CORNER + 1);
type Row = { kind: "capF" | "filletF" | "wall" | "filletB" | "capB"; a: number };
const ROWS: Row[] = [
  ...CAP_RHO.map((a) => ({ kind: "capF" as const, a })),
  ...Array.from({ length: N_FILLET + 1 }, (_, k) => ({ kind: "filletF" as const, a: (k / N_FILLET) * (Math.PI / 2) })),
  ...GROOVE_U.map((a) => ({ kind: "wall" as const, a })),
  ...Array.from({ length: N_FILLET + 1 }, (_, k) => ({ kind: "filletB" as const, a: ((N_FILLET - k) / N_FILLET) * (Math.PI / 2) })),
  ...[...CAP_RHO].reverse().map((a) => ({ kind: "capB" as const, a })),
];
const V = ROWS.length;
/** Band index ranges per material group: front cap, side (fillets + wall), back cap. */
const FRONT_END = CAP_RHO.length; // bands [0, FRONT_END)
const BACK_START = V - 1 - CAP_RHO.length; // bands [BACK_START, V-1)

const SIGN: [number, number][] = [
  [1, 1],
  [-1, 1],
  [-1, -1],
  [1, -1],
];

/** Outline point at inset i for sample c (0..P-1); writes [x, y, nx, ny]. */
const outline = (hw: number, hh: number, rc: readonly number[], i: number, c: number, out: number[]) => {
  const k = Math.floor(c / (N_CORNER + 1));
  const j = c % (N_CORNER + 1);
  const th = (k + j / N_CORNER) * (Math.PI / 2);
  const m = Math.max(rc[k], i);
  const r = Math.max(rc[k] - i, 0);
  const [sx, sy] = SIGN[k];
  const cx = sx * Math.max(hw - m, 0);
  const cy = sy * Math.max(hh - m, 0);
  out[0] = cx + r * Math.cos(th);
  out[1] = cy + r * Math.sin(th);
  out[2] = Math.cos(th);
  out[3] = Math.sin(th);
};

export class Slab {
  readonly geometry: BufferGeometry;
  private pos: Float32Array;
  private nor: Float32Array;
  private uv: Float32Array;
  private tf: Float32Array;

  constructor() {
    const n = P * V;
    this.pos = new Float32Array(n * 3);
    this.nor = new Float32Array(n * 3);
    this.uv = new Float32Array(n * 2);
    this.tf = new Float32Array(n * 3);
    const idx: number[] = [];
    for (let r = 0; r < V - 1; r++)
      for (let c = 0; c < P; c++) {
        const c1 = (c + 1) % P;
        const a = r * P + c, b = (r + 1) * P + c, d = (r + 1) * P + c1, e = r * P + c1;
        idx.push(a, b, d, a, d, e);
      }
    const g = new BufferGeometry();
    g.setIndex(idx);
    g.setAttribute("position", new BufferAttribute(this.pos, 3));
    g.setAttribute("normal", new BufferAttribute(this.nor, 3));
    g.setAttribute("uv", new BufferAttribute(this.uv, 2));
    g.setAttribute("tfPos", new BufferAttribute(this.tf, 3));
    const per = P * 6;
    g.addGroup(0, FRONT_END * per, 0);
    g.addGroup(FRONT_END * per, (BACK_START - FRONT_END) * per, 1);
    g.addGroup(BACK_START * per, (V - 1 - BACK_START) * per, 2);
    g.boundingSphere = new Sphere(new Vector3(), 1);
    this.geometry = g;
  }

  update(s: SlabSpec) {
    const rc = typeof s.rc === "number" ? [s.rc, s.rc, s.rc, s.rc] : [...s.rc];
    const half = s.d / 2;
    // fillets can never exceed the depth or the outline
    let reF = Math.max(0, Math.min(s.reF, s.d, s.hw, s.hh));
    let reB = Math.max(0, Math.min(s.reB, s.d, s.hw, s.hh));
    if (reF + reB > s.d) {
      const k = s.d / (reF + reB);
      reF *= k;
      reB *= k;
    }
    for (let k = 0; k < 4; k++) rc[k] = Math.max(0, Math.min(rc[k], s.hw, s.hh));
    const zTop = half - reF, zBot = -half + reB;
    const wallLen = zTop - zBot;
    const w = Math.min(s.seamWidth ?? 0.1, wallLen * 0.9);
    const seamZ = Math.min(zTop - w / 2, Math.max(zBot + w / 2, s.seamZ ?? (zTop + zBot) / 2));
    const g = Math.min(s.seamDepth ?? 0, Math.min(s.hw, s.hh) * 0.5);
    const bF = s.bulgeF ?? 0, bB = s.bulgeB ?? 0;
    const [ox, oy] = s.origin ?? [0, 0];
    const [us, vs] = s.uvSize ?? [2 * s.hw, 2 * s.hh];
    const o = [0, 0, 0, 0];
    const edge = [0, 0, 0, 0];

    for (let r = 0; r < V; r++) {
      const row = ROWS[r];
      for (let c = 0; c < P; c++) {
        let x: number, y: number, z: number, nx: number, ny: number, nz: number;
        if (row.kind === "capF" || row.kind === "capB") {
          const front = row.kind === "capF";
          outline(s.hw, s.hh, rc, front ? reF : reB, c, edge);
          const rho = row.a;
          x = edge[0] * rho;
          y = edge[1] * rho;
          const R2 = Math.max(edge[0] * edge[0] + edge[1] * edge[1], 1e-9);
          const b = front ? bF : bB;
          z = front ? half + b * (1 - rho * rho) : -half - b * (1 - rho * rho);
          // dome slope: n ∝ (2b·r/R² · radial, ±1)
          const k = (2 * b) / R2;
          nx = k * x;
          ny = k * y;
          nz = front ? 1 : -1;
        } else {
          let inset: number, nOut: number, nZ: number;
          if (row.kind === "filletF") {
            inset = reF * (1 - Math.sin(row.a));
            z = zTop + reF * Math.cos(row.a);
            nOut = Math.sin(row.a);
            nZ = Math.cos(row.a);
          } else if (row.kind === "filletB") {
            inset = reB * (1 - Math.sin(row.a));
            z = zBot - reB * Math.cos(row.a);
            nOut = Math.sin(row.a);
            nZ = -Math.cos(row.a);
          } else {
            const u = row.a;
            z = seamZ + (w / 2) * u;
            inset = (g * (1 + Math.cos(Math.PI * u))) / 2;
            const slope = w > 1e-6 ? (-g * Math.PI * Math.sin(Math.PI * u)) / w : 0;
            const l = Math.hypot(1, slope);
            nOut = 1 / l;
            nZ = slope / l;
          }
          outline(s.hw, s.hh, rc, inset, c, o);
          x = o[0];
          y = o[1];
          nx = nOut * o[2];
          ny = nOut * o[3];
          nz = nZ;
        }
        const l = Math.hypot(nx, ny, nz) || 1;
        const v = r * P + c;
        this.pos[v * 3] = x;
        this.pos[v * 3 + 1] = y;
        this.pos[v * 3 + 2] = z;
        this.nor[v * 3] = nx / l;
        this.nor[v * 3 + 1] = ny / l;
        this.nor[v * 3 + 2] = nz / l;
        this.uv[v * 2] = (x + ox) / us + 0.5;
        this.uv[v * 2 + 1] = (y + oy) / vs + 0.5;
        this.tf[v * 3] = x + ox;
        this.tf[v * 3 + 1] = y + oy;
        this.tf[v * 3 + 2] = z;
      }
    }
    const g0 = this.geometry;
    g0.attributes.position.needsUpdate = true;
    g0.attributes.normal.needsUpdate = true;
    g0.attributes.uv.needsUpdate = true;
    g0.attributes.tfPos.needsUpdate = true;
    g0.boundingSphere!.radius = Math.hypot(s.hw, s.hh, half + Math.max(bF, bB)) + 0.01;
  }

  dispose() {
    this.geometry.dispose();
  }
}

==== 5657 project/src/core/materials/sweep.ts
// Material transitions. A material's look is a plain number tree (MatState), so it can live
// inside era definitions. Between eras the change does not fade globally: a front travels
// along the object (top → bottom in object space, attribute `tfPos`) and each fragment flips
// from state A to state B as it passes, with a thin light band riding the front — the
// TIMEFORGE "time scan". Clearcoat, sheen and iridescence blend with the same progress.

import { Color, MeshPhysicalMaterial, SRGBColorSpace, type Side, type Texture } from "three";
import { patchSoftboxOnly } from "./softboxOnly.ts";

export type Rgb = [number, number, number];
export type MatState = {
  color: Rgb;
  rough: number;
  metal: number;
  cc: number;
  ccRough: number;
  sheen: number;
  irid: number;
  aniso: number;
  emissive: Rgb;
  emissiveI: number;
};

export const hex = (h: string): Rgb => [
  parseInt(h.slice(1, 3), 16) / 255,
  parseInt(h.slice(3, 5), 16) / 255,
  parseInt(h.slice(5, 7), 16) / 255,
];

export const mat = (color: string, o: Partial<Omit<MatState, "color">> = {}): MatState => ({
  color: hex(color),
  rough: 0.5,
  metal: 0,
  cc: 0,
  ccRough: 0.1,
  sheen: 0,
  irid: 0,
  aniso: 0,
  emissive: [0, 0, 0],
  emissiveI: 0,
  ...o,
});

/** Where the scan front is: 0 = not started (all A), 1 = done (all B). */
export type Sweep = { progress: number; top: number; bottom: number; band: number };

type TfUniforms = {
  tfColor2: { value: Color };
  tfRough2: { value: number };
  tfMetal2: { value: number };
  tfFront: { value: number };
  tfSoft: { value: number };
  tfBand: { value: number };
  tfBandW: { value: number };
  tfBandColor: { value: Color };
};

const BAND_COLOR = new Color("#bfeff2"); // light cyan, never neon

type MatOpts = { map?: Texture; emissiveMap?: Texture; side?: Side; transparent?: boolean };
const defined = (o: MatOpts) => Object.fromEntries(Object.entries(o).filter(([, v]) => v !== undefined));

export const sweepMaterial = (o: MatOpts = {}) => {
  const m = new MeshPhysicalMaterial(defined(o));
  const u: TfUniforms = {
    tfColor2: { value: new Color() },
    tfRough2: { value: 0.5 },
    tfMetal2: { value: 0 },
    tfFront: { value: 1e4 },
    tfSoft: { value: 0.35 },
    tfBand: { value: 0 },
    tfBandW: { value: 0.09 },
    tfBandColor: { value: BAND_COLOR.clone() },
  };
  m.userData.tf = u;
  m.onBeforeCompile = (shader) => {
    patchSoftboxOnly(shader);
    Object.assign(shader.uniforms, u);
    shader.vertexShader = shader.vertexShader
      .replace("#include <common>", "#include <common>\nattribute vec3 tfPos;\nvarying vec3 vTf;")
      .replace("#include <begin_vertex>", "#include <begin_vertex>\nvTf = tfPos;");
    shader.fragmentShader = shader.fragmentShader
      .replace(
        "#include <common>",
        `#include <common>
uniform vec3 tfColor2; uniform float tfRough2; uniform float tfMetal2; uniform float tfFront; uniform float tfSoft;
uniform float tfBand; uniform float tfBandW; uniform vec3 tfBandColor;
varying vec3 vTf;`,
      )
      .replace(
        "#include <color_fragment>",
        "#include <color_fragment>\nfloat tfk = smoothstep(tfFront - tfSoft, tfFront + tfSoft, vTf.y);\ndiffuseColor.rgb = mix(diffuseColor.rgb, tfColor2, tfk);",
      )
      .replace("#include <roughnessmap_fragment>", "#include <roughnessmap_fragment>\nroughnessFactor = mix(roughnessFactor, tfRough2, tfk);")
      .replace("#include <metalnessmap_fragment>", "#include <metalnessmap_fragment>\nmetalnessFactor = mix(metalnessFactor, tfMetal2, tfk);")
      .replace(
        "#include <emissivemap_fragment>",
        "#include <emissivemap_fragment>\nfloat tfd = (vTf.y - tfFront) / tfBandW;\ntotalEmissiveRadiance += tfBandColor * tfBand * exp(-tfd * tfd);",
      );
  };
  m.customProgramCacheKey = () => "tf-sweep";
  return m;
};

// PRECISION easing vocabulary. Every curve is a pure function of normalised time, so the
// whole film stays deterministic: same frame in, same pose out.

export const clamp = (x: number, lo = 0, hi = 1) => Math.min(hi, Math.max(lo, x));
export const mix = (a: number, b: number, t: number) => a + (b - a) * t;
export const remap = (x: number, a: number, b: number) => clamp((x - a) / (b - a));

export const smoothstep = (t: number) => {
  const x = clamp(t);
  return x * x * (3 - 2 * x);
};

/** C2-continuous: zero velocity and acceleration at both ends. The house curve. */
export const smootherstep = (t: number) => {
  const x = clamp(t);
  return x * x * x * (x * (x * 6 - 15) + 10);
};

/** CSS-style cubic bezier easing (x1,y1,x2,y2), solved by Newton + bisection. */
export const bezier = (x1: number, y1: number, x2: number, y2: number) => {
  const cx = 3 * x1, bx = 3 * (x2 - x1) - cx, ax = 1 - cx - bx;
  const cy = 3 * y1, by = 3 * (y2 - y1) - cy, ay = 1 - cy - by;
  const sx = (t: number) => ((ax * t + bx) * t + cx) * t;
  const sy = (t: number) => ((ay * t + by) * t + cy) * t;
  const dx = (t: number) => (3 * ax * t + 2 * bx) * t + cx;
  return (x: number) => {
    const X = clamp(x);
    let t = X;
    for (let i = 0; i < 8; i++) {
      const e = sx(t) - X;
      const d = dx(t);
      if (Math.abs(e) < 1e-6) return sy(t);
      if (Math.abs(d) < 1e-6) break;
      t -= e / d;
    }
    let lo = 0, hi = 1;
    t = X;
    for (let i = 0; i < 30; i++) {
      const v = sx(t);
      if (Math.abs(v - X) < 1e-6) break;
      if (v < X) lo = t;
      else hi = t;
      t = (lo + hi) / 2;
    }
    return sy(t);
  };
};

// Named curves, tuned for product cinematography (long, confident tails; no bounce).
export const ease = {
  /** Default move: decisive start, very long settle. */
  glide: bezier(0.45, 0, 0.12, 1),
  /** Symmetric, weighty. Camera and large objects. */
  inOut: bezier(0.65, 0, 0.35, 1),
  /** Soft symmetric for subtle drifts. */
  sine: (t: number) => 0.5 - 0.5 * Math.cos(Math.PI * clamp(t)),
  /** Starts with energy (a magnet letting go), long deceleration. */
  release: bezier(0.2, 0.7, 0.1, 1),
  /** Gathers speed and arrives fast (magnetic pull into a dock). */
  attract: bezier(0.55, 0, 0.95, 0.55),
  /** Typographic reveal. */
  type: bezier(0.2, 0, 0, 1),
  out: bezier(0, 0, 0.2, 1),
  in: bezier(0.6, 0, 1, 1),
  smoother: smootherstep,
};

/** Eased progress of `frame` through [start, end]. */
export const seg = (frame: number, start: number, end: number, curve: (t: number) => number = ease.inOut) =>
  curve(remap(frame, start, end));

/**
 * Critically damped settle used after a mechanical stop: decays to zero with at most one
 * tiny overshoot. `t` in frames since the stop, `amp` the initial offset.
 */
export const settle = (t: number, amp: number, freq = 0.11, damping = 0.16) =>
  t <= 0 ? 0 : amp * Math.exp(-damping * t) * Math.cos(freq * t * Math.PI);

// Keyframe tracks with C1 continuity. Interior keys pass through with Catmull-Rom tangents
// (so a camera never "kinks" when one move hands over to the next); `hold` keys and the
// ends get zero tangents (a soft ease in/out). Tangents are clamped Fritsch–Carlson style
// so a curve never overshoots its keys — no accidental bounces.

/**
 * `m` overrides the tangent (units per frame), e.g. to arrive at speed for a magnetic snap;
 * `stop` makes the key an impact: it is reached at `m` and left at rest.
 */
export type Key = { f: number; v: number[]; hold?: boolean; m?: number[]; stop?: boolean };

const hermite = (p0: number, p1: number, m0: number, m1: number, t: number, h: number) => {
  const t2 = t * t, t3 = t2 * t;
  return (2 * t3 - 3 * t2 + 1) * p0 + (t3 - 2 * t2 + t) * h * m0 + (-2 * t3 + 3 * t2) * p1 + (t3 - t2) * h * m1;
};

const tangent = (keys: Key[], i: number, c: number) => {
  const k = keys[i];
  if (k.m) return k.m[c];
  if (k.hold || i === 0 || i === keys.length - 1) return 0;
  const a = keys[i - 1], b = keys[i + 1];
  const m = (b.v[c] - a.v[c]) / (b.f - a.f);
  // Monotone clamp: no overshoot past either neighbour.
  const d0 = (k.v[c] - a.v[c]) / (k.f - a.f);
  const d1 = (b.v[c] - k.v[c]) / (b.f - k.f);
  if (d0 * d1 <= 0) return 0;
  const lim = 3 * Math.min(Math.abs(d0), Math.abs(d1));
  return Math.sign(m) * Math.min(Math.abs(m), lim);
};

/** Sample a multi-channel track at `frame`. */
export const sample = (keys: Key[], frame: number): number[] => {
  if (frame <= keys[0].f) return keys[0].v.slice();
  const last = keys[keys.length - 1];
  if (frame >= last.f) return last.v.slice();
  let i = 0;
  while (i < keys.length - 2 && frame >= keys[i + 1].f) i++;
  const a = keys[i], b = keys[i + 1];
  const h = b.f - a.f;
  const t = (frame - a.f) / h;
  return a.v.map((_, c) =>
    hermite(a.v[c], b.v[c], a.stop ? 0 : tangent(keys, i, c), tangent(keys, i + 1, c), t, h),
  );
};

/** Convenience: build keys from [frame, ...values] tuples; append "hold" to pin a key. */
export const keys = (...rows: (number | "hold")[][]): Key[] =>
  rows.map((r) => {
    const hold = r[r.length - 1] === "hold";
    const nums = r.filter((x): x is number => typeof x === "number");
    return { f: nums[0], v: nums.slice(1), hold };
  });

/**
 * Render layer for additive / volumetric effects (light shafts, glows, halos, beams). Put such
 * meshes on this layer ONLY (`mesh.layers.set(FX_LAYER)`): the camera still renders them, but the
 * depth-based passes (GTAO, depth of field) skip them. Large transparent volumes on the default
 * layer corrupt those passes and can silently blank the whole frame.
 */
export const FX_LAYER = 1;

/** Run a pass with the FX layer hidden from the camera (depth/normal passes must not see effects). */
export const withoutFx = <P extends Pass>(pass: P, camera: Camera): P => {
  const render = pass.render.bind(pass);
  pass.render = (renderer, writeBuffer, readBuffer, deltaTime, maskActive) => {
    camera.layers.disable(FX_LAYER);
    try {
      render(renderer, writeBuffer, readBuffer, deltaTime, maskActive);
    } finally {
      camera.layers.enable(FX_LAYER);
    }
  };
  return pass;
};

/**
 * Replaces non-finite pixels (NaN/Inf from a faulty custom shader) right after the scene render.
 * Without it, bloom spreads a single NaN pixel across the whole frame and the frame renders blank
 * with no error — found in testing with a custom light-shaft shader.
 */
const NanGuardShader = {
  uniforms: { tDiffuse: { value: null } },
  vertexShader: /* glsl */ `varying vec2 vUv; void main(){ vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position,1.0); }`,
  fragmentShader: /* glsl */ `uniform sampler2D tDiffuse; varying vec2 vUv;
    void main(){ vec4 c = texture2D(tDiffuse, vUv);
      if (any(isnan(c)) || any(isinf(c))) c = vec4(0.0, 0.0, 0.0, 1.0);
      gl_FragColor = clamp(c, 0.0, 64.0); }`,
};

const GradeShader = {
  uniforms: {
    tDiffuse: { value: null },
    uTime: { value: 0 },
    uVignette: { value: 0.14 },
    uGrain: { value: 0.012 },
    uRes: { value: new Vector2(1080, 1920) },

  vertexShader: /* glsl */ `varying vec2 vUv; void main(){ vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position,1.0); }`,
  fragmentShader: /* glsl */ `

    varying vec2 vUv;
    float hash(vec2 p){ p = fract(p * vec2(443.897, 441.423)); p += dot(p, p.yx + 19.19); return fract((p.x + p.y) * p.x); }
    void main(){
      vec4 c = texture2D(tDiffuse, vUv);
      float l = dot(c.rgb, vec3(0.2126, 0.7152, 0.0722));

      c.rgb += (1.0 - smoothstep(0.0, 0.5, l)) * vec3(-0.004, 0.0, 0.006);

      float g = hash(vUv * uRes + uTime * 17.0) - 0.5;
      c.rgb += g * uGrain;
      gl_FragColor = c;
    }`,
};

// PaperMaterial — the single material system every PAPERWORLD object is made of.
//
// Real cardstock reads through three things at once: low-frequency mottling (pulp density),
// fibres (short bright/dark hairs), and a cut edge that is paler than the dyed face. Here
// all three are procedural and seeded, so every render of every frame is identical.
//
// UVs are in scene units (ExtrudeGeometry's world UV generator uses shape coordinates), so
// the grain has the same physical scale on a door, a floor or a puppet's sleeve.

import {
  CanvasTexture,
  Color,
  DoubleSide,
  LinearMipmapLinearFilter,
  MeshStandardMaterial,
  NoColorSpace,
  RepeatWrapping,
  SRGBColorSpace,
  ShaderChunk,
  type Texture,
} from "three";
import { PAPER, PALETTE } from "../tokens.ts";

const SIZE = 1024;

const mulberry32 = (seed: number) => () => {
  seed |= 0;
  seed = (seed + 0x6d2b79f5) | 0;
  let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
  t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
  return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
};

/** Tileable value noise sampled on the SIZE² grid (`cells` lattice cells per side). */
const tileNoise = (cells: number, rnd: () => number) => {
  const lattice = new Float32Array(cells * cells).map(() => rnd());
  const out = new Float32Array(SIZE * SIZE);
  const k = cells / SIZE;
  for (let y = 0; y < SIZE; y++) {
    const fy = y * k, y0 = Math.floor(fy), ty = fy - y0;
    const sy = ty * ty * (3 - 2 * ty);
    const r0 = (y0 % cells) * cells, r1 = ((y0 + 1) % cells) * cells;
    for (let x = 0; x < SIZE; x++) {
      const fx = x * k, x0 = Math.floor(fx), tx = fx - x0;
      const sx = tx * tx * (3 - 2 * tx);
      const c0 = x0 % cells, c1 = (x0 + 1) % cells;
      const a = lattice[r0 + c0] + (lattice[r0 + c1] - lattice[r0 + c0]) * sx;
      const b = lattice[r1 + c0] + (lattice[r1 + c1] - lattice[r1 + c0]) * sx;
      out[y * SIZE + x] = a + (b - a) * sy;
    }
  }
  return out;
};

type GrainMaps = { albedo: Texture; bump: Texture };
let maps: GrainMaps | null = null;

/** Draw the fibre layer: short curved hairs, wrapped so the tile repeats seamlessly. */
const fibres = (rnd: () => number) => {
  const c = document.createElement("canvas");
  c.width = c.height = SIZE;
  const g = c.getContext("2d")!;
  g.fillStyle = "rgb(128,128,128)";
  g.fillRect(0, 0, SIZE, SIZE);
  g.lineCap = "round";
  for (let i = 0; i < 5200; i++) {
    const x = rnd() * SIZE, y = rnd() * SIZE;
    const len = 6 + rnd() ** 2 * 46;
    const a = rnd() * Math.PI * 2;
    const bend = (rnd() - 0.5) * 0.9;
    const light = rnd() < 0.62;
    const alpha = 0.05 + rnd() * 0.11;
    g.strokeStyle = light ? `rgba(255,255,255,${alpha})` : `rgba(0,0,0,${alpha * 0.8})`;
    g.lineWidth = 0.5 + rnd() * 1.1;
    for (const ox of [-SIZE, 0, SIZE])
      for (const oy of [-SIZE, 0, SIZE]) {
        const px = x + ox, py = y + oy;
        if (px < -60 || px > SIZE + 60 || py < -60 || py > SIZE + 60) continue;
        g.beginPath();
        g.moveTo(px, py);
        g.quadraticCurveTo(
          px + Math.cos(a + bend) * len * 0.5,
          py + Math.sin(a + bend) * len * 0.5,
          px + Math.cos(a) * len,
          py + Math.sin(a) * len,
        );
        g.stroke();
      }
  }
  return g.getImageData(0, 0, SIZE, SIZE).data;
};

const build = (): GrainMaps => {
  const rnd = mulberry32(20261028);
  const m1 = tileNoise(4, rnd), m2 = tileNoise(12, rnd), m3 = tileNoise(40, rnd), fine = tileNoise(256, rnd);
  const fib = fibres(rnd);

  const make = (fn: (i: number) => number) => {
    const c = document.createElement("canvas");
    c.width = c.height = SIZE;
    const g = c.getContext("2d")!;
    const img = g.createImageData(SIZE, SIZE);
    for (let i = 0; i < SIZE * SIZE; i++) {
      const v = Math.max(0, Math.min(255, Math.round(fn(i) * 255)));
      img.data[i * 4] = img.data[i * 4 + 1] = img.data[i * 4 + 2] = v;
      img.data[i * 4 + 3] = 255;
    }
    g.putImageData(img, 0, 0);
    return c;
  };

  // Albedo multiplier: ~0.965 mean, pulp mottling ±3 %, fibres ±4 %, tooth ±1.5 %.
  const albedoCanvas = make((i) => {
    const mottle = (m1[i] - 0.5) * 0.5 + (m2[i] - 0.5) * 0.35 + (m3[i] - 0.5) * 0.15;
    const f = (fib[i * 4] - 128) / 128;
    return 0.965 + mottle * 0.06 + f * 0.05 + (fine[i] - 0.5) * 0.03;
  });
  // Height: fibres stand proud, tooth gives the matte micro-relief.
  const bumpCanvas = make((i) => {
    const f = (fib[i * 4] - 128) / 128;
    return 0.5 + f * 0.35 + (fine[i] - 0.5) * 0.35 + (m3[i] - 0.5) * 0.2;
  });

  const tex = (c: HTMLCanvasElement, srgb: boolean) => {
    const t = new CanvasTexture(c);
    t.wrapS = t.wrapT = RepeatWrapping;
    t.repeat.set(1 / PAPER.grainTile, 1 / PAPER.grainTile);
    t.minFilter = LinearMipmapLinearFilter;
    t.anisotropy = 8;
    t.colorSpace = srgb ? SRGBColorSpace : NoColorSpace;
    t.needsUpdate = true;
    return t;
  };
  return { albedo: tex(albedoCanvas, true), bump: tex(bumpCanvas, false) };
};

const cache = new Map<string, MeshStandardMaterial>();

const resolve = (c: string) => (c in PALETTE ? PALETTE[c as keyof typeof PALETTE] : c);

const CORE = new Color("#fff9ee");

// three's screen-space bump mapping divides by the surface's screen derivatives; on a sliver seen exactly
// edge-on (or a software rasteriser's helper pixels) those can vanish and the normal becomes NaN, which the
// bloom then smears over the whole frame. Fall back to the geometric normal there.
const SAFE_BUMP = ShaderChunk.bumpmap_pars_fragment
  .replace(
    "vec3 vSigmaX = normalize( dFdx( surf_pos.xyz ) );",
    "vec3 dX = dFdx( surf_pos.xyz );\n\t\tvec3 dY = dFdy( surf_pos.xyz );\n\t\tif ( dot( dX, dX ) < 1e-14 || dot( dY, dY ) < 1e-14 ) return surf_norm;\n\t\tvec3 vSigmaX = normalize( dX );",
  )
  .replace("vec3 vSigmaY = normalize( dFdy( surf_pos.xyz ) );", "vec3 vSigmaY = normalize( dY );")
  .replace(
    "return normalize( abs( fDet ) * surf_norm - vGrad );",
    "vec3 pn = abs( fDet ) * surf_norm - vGrad;\n\t\tfloat l2 = dot( pn, pn );\n\t\treturn l2 > 1e-12 ? pn * inversesqrt( l2 ) : surf_norm;",
  );

const make = (color: string, o: PaperOpts, edge: boolean) => {
  const { albedo, bump } = grainMaps();
  const col = new Color(resolve(color));
  if (edge) col.lerp(CORE, o.core ?? 0.32);
  const m = new MeshStandardMaterial({
    color: col,
    map: albedo,
    bumpMap: bump,
    bumpScale: (edge ? 0.35 : 0.9) * (o.relief ?? 1),
    roughness: o.roughness ?? 0.93,
    metalness: 0,
    ...(o.doubleSide ? { side: DoubleSide } : {}),
  });
  m.onBeforeCompile = (sh) => {
    sh.fragmentShader = sh.fragmentShader.replace("#include <bumpmap_pars_fragment>", SAFE_BUMP);
  };
  m.customProgramCacheKey = () => "paper-safe-bump";
  if (o.emissive) {
    m.emissive = new Color(resolve(o.emissive));
    m.emissiveIntensity = o.emissiveIntensity ?? 1;
  }
  return m;
};

  `${color}|${o.relief ?? 1}|${o.roughness ?? 0.93}|${o.emissive ?? ""}|${o.emissiveIntensity ?? 1}|${o.doubleSide ? 1 : 0}|${o.core ?? 0.32}|${edge ? "e" : "f"}`;

// Page bend — one analytic deformation shared by a leaf and everything printed or glued on it.
//
// A leaf lives in its own frame: x runs from the spine (x = 0) to the fore-edge (x = W), y is the page normal
// (lift above the paper), z runs along the spine. Turning bends every row into a circular arc that starts at
// the spine with angle `theta` and curves by `k` per cm (k varies along z so a corner leads the turn):
//   a(s) = theta + k·s,   P(s) = ((sin a − sin theta)/k, (cos theta − cos a)/k),   normal n(s) = (−sin a, cos a)
// A vertex at (s, h, z) lands at P(s) + n(s)·h·lift. Because it is evaluated in the vertex shader on world
// positions, cut-outs, puppets, threads and printed text glued to a page bend with it in real 3D (lift and
// shadows included) without render-to-texture. Every material on a leaf shares that leaf's uniforms.

import { Matrix4, MeshDepthMaterial, RGBADepthPacking, Vector2, Vector4, type Material, type Texture } from "three";
import { createContext, useContext } from "react";

export type BendUniforms = {
  uPage: { value: Matrix4 };
  uPageInv: { value: Matrix4 };
  uTheta: { value: number };
  uK0: { value: number };
  uKz: { value: number };
  uLift: { value: number };
  /** Surfaces this leaf's cut-outs must stay clear of (see "Clearance" below). */
  uCeilR: { value: Vector4 };
  uCeilL: { value: Vector4 };
  uFloor: { value: Vector2 };
};

/** No surface (theta < 0 disables a ceiling). */
export const NO_CEIL = new Vector4(-1, 0, 0, 0);

export const makeBend = (): BendUniforms => ({
  uPage: { value: new Matrix4() },
  uPageInv: { value: new Matrix4() },
  uTheta: { value: 0 },
  uK0: { value: 0 },
  uKz: { value: 0 },
  uLift: { value: 1 },
  uCeilR: { value: NO_CEIL.clone() },
  uCeilL: { value: NO_CEIL.clone() },
  uFloor: { value: new Vector2(-100, -100) },
});

// Clearance: lifted cut-outs never pierce paper. Each vertex's lift is compressed (all layers by the same factor,
// so their order is kept) just enough to fit the gap to the page above it (ceiling: the leaf/cover turning over it,
// one for the right side and one for the left) or to the stack below when it faces down (floor). The gap changes
// continuously as pages move, so cut-outs settle flat under a landing page and rise as it lifts away — no
// visibility toggles, no lift ramps, nothing coplanar while visible. A ceiling is (theta, k0, kz, frame y) of a
// leaf; heights are taken along its arc at s = |x|, which underestimates a curled page (a little extra squash).

/** The bend of the leaf a component sits on (null = not on a leaf: no deformation). */
export const BendContext = createContext<BendUniforms | null>(null);
export const useBend = () => useContext(BendContext);

const DECL = /* glsl */ `
uniform mat4 uPage; uniform mat4 uPageInv;
uniform float uTheta; uniform float uK0; uniform float uKz; uniform float uLift;
uniform vec4 uCeilR; uniform vec4 uCeilL; uniform vec2 uFloor;
float sbArcY(vec4 c, float s, float z) {
  float k = c.y + c.z * z;
  if (abs(k) < 1e-4) return c.w + s * sin(c.x + 0.5 * k * s);
  return c.w + (cos(c.x) - cos(c.x + k * s)) / k;
}
vec3 sbBend(vec3 w, out mat3 R) {
  vec4 p = uPageInv * vec4(w, 1.0);
  float s = max(p.x, 0.0);
  float h = p.y * uLift;
  float k = uK0 + uKz * p.z;
  float a = uTheta + k * s;
  vec2 P;
  if (abs(k) < 1e-4) { float m = uTheta + 0.5 * k * s; P = s * vec2(cos(m), sin(m)); }
  else P = vec2(sin(a) - sin(uTheta), cos(uTheta) - cos(a)) / k;
  vec2 n = vec2(-sin(a), cos(a));
  // clearance (frame = world translated: uPage is a pure translation for leaves)
  if (abs(h) > 1e-5) {
    vec3 Lw = (uPage * vec4(P, p.z, 1.0)).xyz;
    float rise = h * n.y;
    float room = 1e3;
    if (rise > 0.0) {
      bool right = Lw.x >= 0.0;
      vec4 c = right ? uCeilR : uCeilL;
      bool valid = right ? (c.x >= 0.0 && c.x < 1.5707963) : (c.x > 1.5707963);
      if (valid) room = (sbArcY(c, abs(Lw.x), p.z) - Lw.y - 0.003) / max(abs(n.y), 1e-3);
    } else if (rise < 0.0) {
      float fl = Lw.x >= 0.0 ? uFloor.x : uFloor.y;
      room = (Lw.y - fl - 0.003) / max(abs(n.y), 1e-3);
    }
    // keep layers ordered and a hair off their own paper even when squashed (no coplanar z-fight)
    float e0 = 0.0025 * (1.0 - clamp(room / 0.8, 0.0, 1.0));
    float f = clamp((room - e0) / 0.8, 0.0, 1.0);
    h = sign(h) * (e0 + abs(h) * f);
  }
  float c = cos(a), sn = sin(a);
  R = mat3(c, sn, 0.0, -sn, c, 0.0, 0.0, 0.0, 1.0);
  return (uPage * vec4(P + n * h, p.z, 1.0)).xyz;
}
`;

export const bendMaterial = <M extends Material>(m: M, U: BendUniforms, extra?: (sh: { fragmentShader: string; uniforms: Record<string, unknown> }) => void): M => {

    sh.vertexShader = inject(sh.vertexShader, true);
    extra?.(sh);
  };
  const key = m.customProgramCacheKey?.() ?? "";
  m.customProgramCacheKey = () => `sb-bend|${key}`;
  return m;
};

export type BendState = { theta: number; k0: number; kz: number; lift: number };

/** Leaf-frame point (s, h, z) → bent leaf-frame point. */
export const bendPoint = (b: BendState, s: number, h: number, z: number): [number, number, number] => {
  const k = b.k0 + b.kz * z;
  const a = b.theta + k * s;
  let px: number, py: number;
  if (Math.abs(k) < 1e-4) {
    const m = b.theta + 0.5 * k * s;
    px = s * Math.cos(m);
    py = s * Math.sin(m);
  } else {
    px = (Math.sin(a) - Math.sin(b.theta)) / k;
    py = (Math.cos(b.theta) - Math.cos(a)) / k;
  }
  return [px - Math.sin(a) * h * b.lift, py + Math.cos(a) * h * b.lift, z];
};

// Picture-book type: Newsreader (story text, OFL) and Kalam Bold (hand-lettered titles, OFL).
// Bundled in public/fonts; painted canvases need them loaded before the first texture is drawn.
export const STORY_SERIF = "Newsreader";
export const STORY_HAND = "Kalam";

let ready: Promise<void> | null = null;
export const storyFontsReady = (): Promise<void> => {
  if (ready) return ready;
  if (typeof document === "undefined") return (ready = Promise.resolve());
  const handle = delayRender("storybook fonts");
  const faces = [
    new FontFace(STORY_SERIF, `url(${staticFile("fonts/Newsreader-VF.woff2")}) format("woff2")`, { weight: "200 800", style: "normal" }),
    new FontFace(STORY_SERIF, `url(${staticFile("fonts/Newsreader-Italic-VF.woff2")}) format("woff2")`, { weight: "200 800", style: "italic" }),
    new FontFace(STORY_HAND, `url(${staticFile("fonts/Kalam-Bold.ttf")}) format("truetype")`, { weight: "700", style: "normal" }),
  ];
  ready = Promise.all(
    faces.map(async (f) => {
      await f.load();
      (document.fonts as unknown as { add(f: FontFace): void }).add(f);
    }),
  ).then(
    () => continueRender(handle),
    (e) => {
      continueRender(handle);
      throw e;
    },
  );
  return ready;
};

/**
 * Print text on a page canvas (cm space, y up). Wraps to `width`, centred on x. Returns the bottom y.
 * Canvas text is drawn in a flipped y frame, so each line is drawn with a local un-flip.
 */
export const printText = (
  g: CanvasRenderingContext2D,
  text: string,
  x: number,
  y: number,
  o: { size: number; width: number; font?: string; weight?: number; italic?: boolean; color?: string; leading?: number; align?: "center" | "left"; /** Measure only (wrap, return the bottom y), draw nothing. */ dry?: boolean },
) => {
  // fonts are set at 100× and drawn under a 1/100 scale: tiny px sizes in a cm-scaled canvas rasterise badly
  const font = `${o.italic ? "italic " : ""}${o.weight ?? 420} ${o.size * 100}px ${o.font ?? STORY_SERIF}`;
  g.save();
  g.font = font;
  const words = text.split(/\s+/);
  const lines: string[] = [];
  let cur = "";
  for (const w of words) {
    const t = cur ? `${cur} ${w}` : w;
    if (g.measureText(t).width / 100 > o.width && cur) {
      lines.push(cur);
      cur = w;
    } else cur = t;
  }
  if (cur) lines.push(cur);
  const lead = o.size * (o.leading ?? 1.32);
  g.fillStyle = o.color ?? "#3b2a22";
  g.textAlign = o.align ?? "center";
  g.textBaseline = "alphabetic";
  if (!o.dry) lines.forEach((ln, i) => {
    g.save();
    g.translate(x, y - i * lead);
    g.scale(0.01, -0.01);
    g.fillText(ln, 0, 0);
    g.restore();
  });
  g.restore();
  return y - (lines.length - 1) * lead;
};

import { CylinderGeometry, MeshStandardMaterial } from "three";
import { bendDepth, bendMaterial, useBend, type BendUniforms } from "./bend.ts";
import { blob, dot, ellipse, pencil, rect, scribble, shade, type Paint, type Poly } from "./paint.ts";

const pinGeo = new CylinderGeometry(1, 1, 1, 20);
pinGeo.rotateX(Math.PI / 2);
const pinMats = new WeakMap<object, { m: MeshStandardMaterial; d: ReturnType<typeof bendDepth> }>();
const NO_LEAF = {};

/** Brass split pin (a real little metal disc: catches the lamp). */
export const Pin: React.FC<{ x: number; y: number; z?: number; r?: number }> = ({ x, y, z = 0.02, r = 0.14 }) => {
  const U = useBend();
  const res = useMemo(() => {
    const k = (U ?? NO_LEAF) as object;
    let v = pinMats.get(k);
    if (!v) {
      const m = new MeshStandardMaterial({ color: "#c79a3e", metalness: 0.75, roughness: 0.38 });
      if (U) bendMaterial(m, U as BendUniforms);
      v = { m, d: bendDepth(U, null) };
      pinMats.set(k, v);
    }
    return v;
  }, [U]);
  return <mesh geometry={pinGeo} material={res.m} customDepthMaterial={res.d} position={[x, y, z]} scale={[r, r, 0.035]} castShadow receiveShadow />;
};

export type KidLook = {
  skin: string;
  hair: string;

export type KidPose = {
  /** Walk phase in cycles (advance ~1.6 per second when walking). */
  walk?: number;
  /** 0 standing … 1 full stride. */
  stride?: number;
  /** Shoulder angles (rad, 0 = hanging down, + = forward/up for the front arm). */
  armF?: number;
  armB?: number;
  elbowF?: number;
  elbowB?: number;
  /** Head tilt (rad) and eye direction (-1…1, -1…1). */
  head?: number;
  look?: [number, number];
  blink?: number;
  mouth?: "smile" | "open" | "sad" | "flat";
  /** Body lean (rad) and vertical squash/hop offset (cm). */
  lean?: number;
  hop?: number;
  /** Knee bend for crouching (rad, both legs). */
  crouch?: number;
};

const P = (p: Poly | Poly[]) => () => p;

const dotsMarks = (L: KidLook) => (g: CanvasRenderingContext2D, r: () => number) => {
  if (!L.dressDots) return;
  for (let yy = 0; yy < 12; yy += 0.75)
    for (let xx = -3; xx < 3; xx += 0.75) dot(g, xx + ((yy / 0.75) % 2) * 0.37 + (r() - 0.5) * 0.08, yy + (r() - 0.5) * 0.08, 0.12, L.dressDots, 0.11, 0.85);
};

// <Sheet> — one painted, scissor-cut piece of paper glued (or lifted) on a page.
//
// Geometry is a finely subdivided plane covering the piece's bounding box; the painted canvas carries the
// silhouette in its alpha, so edges can be as irregular as a real cut. The plane is subdivided so a page
// bend (bend.ts) curves it smoothly. Shadows use an alpha-tested depth material bent the same way.
// Resources are cached per (leaf, id, resolution): `id` must be unique per leaf.

import React, { createContext, useContext, useMemo } from "react";
import { DoubleSide, MeshStandardMaterial, PlaneGeometry, ShaderChunk, type Material, type Texture } from "three";
import { canvasTexture, hashStr, paintCanvas, type Paint, type Poly } from "./paint.ts";
import { bendDepth, bendMaterial, useBend, type BendUniforms } from "./bend.ts";
import { grainMaps } from "../paperworld/material/paper.ts";

/** Pixels per centimetre for painted canvases (set from the render width by <Book>/<Film>). */
export const ResolutionContext = createContext(60);

// three's bump mapping can produce NaN on slivers seen edge-on (bloom would smear it): guard it.
const SAFE_BUMP = ShaderChunk.bumpmap_pars_fragment
  .replace(
    "vec3 vSigmaX = normalize( dFdx( surf_pos.xyz ) );",
    "vec3 dX = dFdx( surf_pos.xyz );\n\t\tvec3 dY = dFdy( surf_pos.xyz );\n\t\tif ( dot( dX, dX ) < 1e-14 || dot( dY, dY ) < 1e-14 ) return surf_norm;\n\t\tvec3 vSigmaX = normalize( dX );",
  )
  .replace("vec3 vSigmaY = normalize( dFdy( surf_pos.xyz ) );", "vec3 vSigmaY = normalize( dY );")
  .replace(
    "return normalize( abs( fDet ) * surf_norm - vGrad );",
    "vec3 pn = abs( fDet ) * surf_norm - vGrad;\n\t\tfloat l2 = dot( pn, pn );\n\t\treturn l2 > 1e-12 ? pn * inversesqrt( l2 ) : surf_norm;",
  );

const safeBump = (sh: { fragmentShader: string }) => {
  sh.fragmentShader = sh.fragmentShader.replace("#include <bumpmap_pars_fragment>", SAFE_BUMP);
};

/** A lit paper material (optionally following a leaf's bend). */
export const paperMaterial = (opts: { map?: Texture | null; color?: string; bump?: Texture | null; bumpScale?: number; alpha?: boolean; roughness?: number; bend?: BendUniforms | null }) => {
  const m = new MeshStandardMaterial({
    map: opts.map ?? null,
    color: opts.color ?? "#ffffff",
    roughness: opts.roughness ?? 0.9,
    metalness: 0,
    side: DoubleSide,
    bumpMap: opts.bump ?? null,
    bumpScale: opts.bumpScale ?? 0.6,
    alphaTest: opts.alpha ? 0.04 : 0,
    alphaToCoverage: !!opts.alpha,
  });
  if (opts.bend) bendMaterial(m, opts.bend, safeBump);
  else {
    m.onBeforeCompile = (sh) => safeBump(sh);
    m.customProgramCacheKey = () => "sb-safe-bump";
  }
  return m;
};

/** A grain bump texture scaled for a w × h cm surface. */
export const grainFor = (w: number, h: number, tile = 4) => {
  const t = grainMaps().bump.clone();
  t.repeat.set(w / tile, h / tile);
  t.needsUpdate = true;
  return t;
};

type Res = { geo: PlaneGeometry; mat: Material; depth: Material };
const noBend = new Map<string, Res>();
const perLeaf = new WeakMap<BendUniforms, Map<string, Res>>();

const build = (shape: Poly[], paint: Paint, ppc: number, U: BendUniforms | null): Res => {
  const pc = paintCanvas(shape, paint, ppc);
  const segX = Math.max(1, Math.ceil(pc.w / (U ? 0.45 : 4)));
  const segY = Math.max(1, Math.ceil(pc.h / (U ? 0.9 : 4)));
  const geo = new PlaneGeometry(pc.w, pc.h, segX, segY);
  geo.translate(pc.x0 + pc.w / 2, pc.y0 + pc.h / 2, 0);
  const tex = canvasTexture(pc.canvas);
  const mat = paperMaterial({ map: tex, bump: grainFor(pc.w, pc.h), bumpScale: 0.5, alpha: true, bend: U });
  const depth = bendDepth(U, tex, 0.5);
  return { geo, mat, depth };
};

export const useSheet = (id: string, shape: () => Poly | Poly[], paint: Paint): Res => {
  const U = useBend();
  const ppc = useContext(ResolutionContext);
  return useMemo(() => {
    const key = `${id}|${ppc}`;
    const store = U ? (perLeaf.get(U) ?? perLeaf.set(U, new Map()).get(U)!) : noBend;
    let r = store.get(key);
    if (!r) {
      const s = shape();
      const polys = (Array.isArray(s[0][0]) ? s : [s]) as Poly[];
      r = build(polys, { ...paint, seed: paint.seed ?? hashStr(id) }, ppc, U);
      store.set(key, r);
    }
    return r;
    // shape/paint are authored inline and fixed per id: rebuild only when id/leaf/resolution change
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [id, ppc, U]);
};

export type SheetProps = {
  /** Unique per leaf (seeds the paint and keys the cache). */
  id: string;
  shape: () => Poly | Poly[];
  paint: Paint;
  /** Lift above the page in cm (layers: background 0.03 … foreground 0.5). */
  z?: number;
  x?: number;
  y?: number;
  /** In-plane rotation (radians, counter-clockwise). */
  rot?: number;
  scale?: number | [number, number];
  visible?: boolean;
  cast?: boolean;
  children?: React.ReactNode;
};

export const Sheet: React.FC<SheetProps> = ({ id, shape, paint, z = 0.05, x = 0, y = 0, rot = 0, scale = 1, visible = true, cast = true, children }) => {
  const r = useSheet(id, shape, paint);
  const s: [number, number, number] = typeof scale === "number" ? [scale, scale, 1] : [scale[0], scale[1], 1];
  return (
    <group position={[x, y, z]} rotation={[0, 0, rot]} scale={s} visible={visible}>
      <mesh geometry={r.geo} material={r.mat} customDepthMaterial={r.depth} castShadow={cast} receiveShadow />
      {children}
    </group>
  );
};

/** A group in page-plane coordinates rotating about a pivot (puppet joints, swinging signs, kites). */
export const Pivot: React.FC<{ at: [number, number]; rot?: number; z?: number; children: React.ReactNode }> = ({ at, rot = 0, z = 0, children }) => (
  <group position={[at[0], at[1], z]} rotation={[0, 0, rot]}>
    <group position={[-at[0], -at[1], 0]}>{children}</group>
  </group>
);

export const mixLamp = (a: Lamp, b: Lamp, t: number): Lamp => {
  if (t <= 0) return a;
  if (t >= 1) return b;
  const c = (x: string, y: string) => "#" + new Color(x).lerp(new Color(y), t).getHexString();
  const n = (x: number, y: number) => x + (y - x) * t;
  const v = (x: V3, y: V3): V3 => [n(x[0], y[0]), n(x[1], y[1]), n(x[2], y[2])];
  return {
    pos: v(a.pos, b.pos), aim: v(a.aim, b.aim), color: c(a.color, b.color), intensity: n(a.intensity, b.intensity),
    angle: n(a.angle, b.angle), penumbra: n(a.penumbra, b.penumbra), shadowSoft: n(a.shadowSoft, b.shadowSoft),
    sky: c(a.sky, b.sky), ground: c(a.ground, b.ground), hemi: n(a.hemi, b.hemi), fill: c(a.fill, b.fill), fillI: n(a.fillI, b.fillI),
    bg: c(a.bg, b.bg), exposure: n(a.exposure, b.exposure), vignette: n(a.vignette, b.vignette),
  };
};

    uniform sampler2D tDiffuse; uniform float uTime; uniform float uVignette; uniform float uGrain; uniform vec2 uRes;
    varying vec2 vUv;
    float hash(vec2 p){ p = fract(p * vec2(443.897, 441.423)); p += dot(p, p.yx + 19.19); return fract((p.x + p.y) * p.x); }
    void main(){
      vec4 c = texture2D(tDiffuse, vUv);
      float l = dot(c.rgb, vec3(0.2126, 0.7152, 0.0722));
      // lamp-warm highlights, brown (never blue-black) shadows, a gentle print-like S-curve
      c.rgb += smoothstep(0.5, 1.0, l) * vec3(0.008, 0.003, -0.008);
      c.rgb += (1.0 - smoothstep(0.0, 0.4, l)) * vec3(0.014, 0.006, -0.002);
      c.rgb = mix(c.rgb, c.rgb * c.rgb * (3.0 - 2.0 * c.rgb), 0.2);
      vec2 d = (vUv - 0.5) * vec2(1.0, 1.1);
      c.rgb *= 1.0 - uVignette * smoothstep(0.32, 0.95, length(d));
      float g = hash(vUv * uRes + uTime * 17.0) - 0.5;
      c.rgb += g * uGrain * (0.6 + 0.4 * (1.0 - l));
      gl_FragColor = c;
    }`,
};

const SanitizeShader = {
  uniforms: { tDiffuse: { value: null }, uMax: { value: 12 } },
  vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
  fragmentShader: `uniform sampler2D tDiffuse; uniform float uMax; varying vec2 vUv;
    void main() {
      vec4 c = texture2D(tDiffuse, vUv);
      if (any(isnan(c)) || any(isinf(c))) c = vec4(0.0, 0.0, 0.0, 1.0);
      gl_FragColor = vec4(clamp(c.rgb, 0.0, uMax), clamp(c.a, 0.0, 1.0));
    }`,
};

export const Stage: React.FC<{ shot: Shot; lamp: Lamp; frame: number; children: React.ReactNode }> = ({ shot, lamp, frame, children }) => {
  const { gl, scene, camera, size } = useThree();

  const rig = useMemo(() => {
    const target = new Object3D();
    const key = new SpotLight("#fff", 3);
    key.castShadow = true;
    key.decay = 0;
    key.shadow.mapSize.set(4096, 4096);
    key.shadow.bias = -0.00006;
    key.shadow.normalBias = 0.004;
    key.shadow.camera.near = 30;
    key.shadow.camera.far = 160;
    key.target = target;
    const hemi = new HemisphereLight("#fff", "#888", 1);
    const fill = new DirectionalLight("#fff", 0.3);
    fill.target = target;
    return { target, key, hemi, fill };
  }, []);

  const chain = useMemo(() => {
    const w = size.width, h = size.height;
    const rt = new WebGLRenderTarget(w, h, { type: HalfFloatType, samples: 4 });
    const composer = new EffectComposer(gl, rt);
    composer.setPixelRatio(1);
    composer.setSize(w, h);
    composer.addPass(new RenderPass(scene, camera));
    composer.addPass(new ShaderPass(SanitizeShader));
    const dof = new BokehPass(scene, camera, { focus: 60, aperture: 0.0, maxblur: 0.0 });
    composer.addPass(dof);
    const bloom = new UnrealBloomPass(new Vector2(w, h), 0.08, 0.5, 0.95);
    composer.addPass(bloom);
    composer.addPass(new OutputPass());
    const grade = new ShaderPass(GradeShader);
    (grade.uniforms.uRes.value as Vector2).set(w, h);
    composer.addPass(grade);
    return { composer, dof, grade };
  }, [gl, scene, camera, size.width, size.height]);

  useLayoutEffect(() => {
    const cam = camera as PerspectiveCamera;
    cam.position.set(...shot.pos);
    cam.up.set(Math.sin(shot.roll ?? 0), Math.cos(shot.roll ?? 0), 0);
    cam.lookAt(...shot.target);
    cam.fov = shot.fov;
    // the camera never comes closer than ~40 cm: a far near plane keeps depth precise for 0.01 mm paper layers
    cam.near = 8;
    cam.far = 600;
    cam.updateProjectionMatrix();
    cam.updateMatrixWorld();
    gl.toneMapping = NeutralToneMapping;
    gl.shadowMap.autoUpdate = false;
    const u = chain.dof.uniforms as unknown as Record<string, { value: number }>;
    const focus = shot.focus ?? new Vector3(...shot.pos).distanceTo(new Vector3(...shot.target));
    u.focus.value = focus;
    u.aperture.value = shot.aperture ?? 0;
    u.maxblur.value = shot.maxBlur ?? 0;
    chain.dof.enabled = (shot.maxBlur ?? 0) > 0 && (shot.aperture ?? 0) > 0;
    chain.grade.uniforms.uTime.value = frame % 997;
    chain.grade.uniforms.uVignette.value = lamp.vignette;
  }, [shot, camera, gl, chain, frame, lamp.vignette]);

  useFrame(() => {
    const L = lamp;
    rig.target.position.set(...L.aim);
    rig.target.updateMatrixWorld();
    rig.key.position.set(...L.pos);
    rig.key.color.set(L.color);
    rig.key.intensity = L.intensity;
    rig.key.angle = L.angle;
    rig.key.penumbra = L.penumbra;
    rig.key.shadow.radius = L.shadowSoft;
    rig.key.updateMatrixWorld();
    rig.hemi.color.set(L.sky);
    rig.hemi.groundColor.set(L.ground);
    rig.hemi.intensity = L.hemi;
    rig.fill.position.set(L.aim[0] + 10, L.aim[1] + 40, L.aim[2] + 60);
    rig.fill.color.set(L.fill);
    rig.fill.intensity = L.fillI;
    rig.fill.updateMatrixWorld();
    scene.background = new Color(L.bg);
    gl.toneMappingExposure = L.exposure;
    gl.shadowMap.needsUpdate = true;
    chain.composer.render();
  }, 1);

  return (
    <>
      <primitive object={rig.target} />
      <primitive object={rig.key} />
      <primitive object={rig.hemi} />
      <primitive object={rig.fill} />
      {children}
    </>
  );
};

// <Thread> — a string or line of thread in page space (kite strings, washing lines, spider silk).
// Rebuilt every frame from its points; bends with the page like everything else.

import React, { useMemo } from "react";
import { BufferAttribute, BufferGeometry, MeshStandardMaterial } from "three";
import { bendDepth, bendMaterial, useBend } from "./bend.ts";
import type { Pt } from "./paint.ts";

const mats = new WeakMap<object, Map<string, { m: MeshStandardMaterial; d: ReturnType<typeof bendDepth> }>>();
const NONE = {};

export const Thread: React.FC<{ pts: Pt[]; width?: number; color?: string; z?: number }> = ({ pts, width = 0.05, color = "#efe7d6", z = 0.3 }) => {
  const U = useBend();
  const res = useMemo(() => {
    const k = (U ?? NONE) as object;
    const store = mats.get(k) ?? mats.set(k, new Map()).get(k)!;
    let v = store.get(color);
    if (!v) {
      const m = new MeshStandardMaterial({ color, roughness: 0.8, side: 2 });
      if (U) bendMaterial(m, U);
      v = { m, d: bendDepth(U, null) };
      store.set(color, v);
    }
    return v;
  }, [U, color]);
  const geo = useMemo(() => {
    const n = pts.length;
    const pos = new Float32Array(n * 2 * 3);
    const nor = new Float32Array(n * 2 * 3);
    for (let i = 0; i < n; i++) {
      const a = pts[Math.max(0, i - 1)], b = pts[Math.min(n - 1, i + 1)];
      let tx = b[0] - a[0], ty = b[1] - a[1];
      const l = Math.hypot(tx, ty) || 1;
      tx /= l;
      ty /= l;
      const ox = -ty * width * 0.5, oy = tx * width * 0.5;
      pos.set([pts[i][0] + ox, pts[i][1] + oy, 0, pts[i][0] - ox, pts[i][1] - oy, 0], i * 6);
      nor.set([0, 0, 1, 0, 0, 1], i * 6);
    }
    const idx: number[] = [];
    for (let i = 0; i < n - 1; i++) {
      const a = i * 2;
      idx.push(a, a + 1, a + 2, a + 1, a + 3, a + 2);
    }
    const g = new BufferGeometry();
    g.setAttribute("position", new BufferAttribute(pos, 3));
    g.setAttribute("normal", new BufferAttribute(nor, 3));
    g.setIndex(idx);
    return g;
  }, [pts, width]);
  return <mesh geometry={geo} material={res.m} customDepthMaterial={res.d} position={[0, 0, z]} castShadow />;
};
