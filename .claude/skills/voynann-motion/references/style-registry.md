# VOYNANN Motion style registry

What each of the nineteen styles is, what this package includes for it, and its known limits. Read-only during buyer sessions.

| ID | Name | Direction | Engine in this package | Known limits |
| --- | --- | --- | --- | --- |
| 01 | PIXELSTORY | Cinematic 2.5D pixel-character storytelling | `kits/pixelstory` (+ fonts) | Lights cast no shadows (paint them); every film designs its own cast; very large layers slow renders |
| 02 | VOXELVERSE | 3D handcrafted voxel worlds | `kits/voxelverse` | One shadowed key light; voxel characters are built per film; keep far rows simple in large worlds |
| 03 | PRECISION | Premium hard-surface product CGI / exploded view | core (studio, post, slab, materials come from this style) | No SDF/pebble geometry kit; soft organic product forms need extra work |
| 04 | PAPERWORLD | Tactile paper-craft storytelling | `kits/paperworld` | Folds are rigid hinges and shears (no paper bending); one puppet rig — new characters are new components |

PRECISION and INNERWORKS have no dedicated kit; plan for a second preview round (see the preview-rounds note in SKILL.md).

**Format:** every style is portrait 9:16 by default and can be made in landscape 16:9 when the buyer asks (SKILL.md › Format): CINÉSTORY, CHARACTER FLOW, PANELVERSE, STORYBOOK, CHRONICLE, BEDAH, CERDIK, NEGERI, TIPIKAL, NEKAT and BONGKAR with a switch in their engines, the other eight directed again from `PRESETS_WIDE`. No square or 4:5.

## What this package contains

One installable `voynann-motion` skill with nineteen selectively loaded style references. Never quote prices. This ZIP contains the generic production kit (starter, core library, style kits for PIXELSTORY, VOXELVERSE, PAPERWORLD, WORLDFORGE, TIMEFORGE, BUILDFORGE, CHARACTER FLOW and PANELVERSE with technical examples, scripts, bundled OFL comic fonts; the CINÉSTORY 3D project with example stories and worlds; the STORYBOOK, CHRONICLE and BEDAH projects with two example scripts each; the CERDIK project with four example stories in four of its five worlds; the NEGERI project with four example days and a started series; the TIPIKAL project with five example topics; the NEKAT project with five example episodes; the BONGKAR project with two example objects) and small quality-bar stills from the author's reference films. It does **not** contain or license the reference projects, stories, product designs, ElevenLabs recordings, music or video renders. Buyers need Node.js, npm and (for audio work) ffmpeg; see `references/setup.md`.
