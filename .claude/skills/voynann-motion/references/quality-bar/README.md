# Quality bar

Seven frames from each reference film (downscaled). Use them to judge whether a new film's
look-dev and preview are in the same quality class — never to copy their stories, characters,
products or layouts. `worldforge.jpg` = Mars, `worldforge-roma.jpg` = Rome, `paperworld.jpg` is from a
540×960 preview, `characterflow.jpg` = three campus frames and four bedroom-at-night frames from two
CHARACTER FLOW validation films directed automatically from a voice-over, `panelverse.jpg` = seven frames of the PANELVERSE reference film "Oke" (punch zoom, freeze panel, 3-up page, diagonal split, TAMAT!, the reveal, the end page), `storybook.jpg` = seven frames of the STORYBOOK example "Mimi dan Payung Kuning" (cover, garden, rain, umbrella, bedroom, rainbow, night), `chronicle.jpg` = seven frames of the CHRONICLE example "Ditangkap Saat Lebaran" (grave at dusk, map with date, burning village, misty forest with counter, hall, route map, writing room). These stills are the author's original renders
and are included only as references.
